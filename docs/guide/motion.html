Stage 4 · engines/audio2face/rigfit and identity

Voice to face motion

This stage makes two things: a 3D face of the creator that can be moved like a puppet, and a small model that listens to speech and works the puppet's strings the way this creator's face moves. Its output is a moving 3D face with no colour or skin; the next stage paints it.

The parts, in plain words

partwhat it iswhere it comes from
a MetaHuman rigEpic Games' professional face puppet: a detailed face mesh of 24,049 points, moved by 263 named controls (jaw open, left lip corner up, brow lower, ...). Setting the controls poses the faceyou supply one (setup); it is someone else's face
their rigthat same puppet, its resting face reshaped to the creator's head. Same 263 controlsbuilt here from the head shape tracked in face clips
Audio2Face-3DNVIDIA's model that turns speech into those 263 control values. Trained on eight other peopleyou supply its two model files
the correctiona small network trained here: it adjusts Audio2Face's controls to fit this creatortrained here, about 40 minutes

How speech becomes a moving face

How the correction is trained

From stage 3 we know what the creator's face actually did in every frame of every clip. That is the answer key. The model is scored on where the face's points end up, never on the control values themselves (many control settings give the same face, so the values are not a fair target).

The clips are split once, for every stage

How good it is

How it is built

Commands

./alive build <creator> --stage motion runs it. By hand, from engines/audio2face/:

python rigfit/recipes/audio-to-mesh/tools/status.py --profile <name>   # done so far, and the next command

A new creator starts as a copy of rigfit/recipes/audio-to-mesh/profiles/_template.py: their name, and which tracked video goes with which soundtrack. The full recipe is engines/audio2face/rigfit/recipes/audio-to-mesh/RECIPE.md; how a rig is reshaped to a person is in engines/audio2face/identity/README.md.

Things that go wrong

every score is low, the mouth looks finethe rig is still the stock face; the identity check flags it. Rebuild step 1
the lips never quite shutknown on both creators (Dr K about 4 mm open). The closure penalty helps a little; more clips help more
