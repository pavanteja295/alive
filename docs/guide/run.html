Run the app

One command starts everything for one creator. You need that creator's trained models in checkpoints/<creator>/; if you don't have them yet, build them first.

./alive check huberman      # everything on disk?
./alive up huberman         # start; about 20 seconds
# open http://127.0.0.1:8800 and ask a question
./alive down                # stop everything

What starts, and how one question flows through it

Four small servers on your machine. The viewer in your browser talks only to the first; it calls the others in turn.

The commands

commanddoes
./alive up <creator>starts voice, face, answers, app, in that order, and waits until each answers
./alive downstops all four and frees the card
./alive statuswhat is running, on which port, and card memory
./alive check [creator]every file the app needs, and what is missing
./alive logs <service> [-f]a service's log: voice, face, style (answers) or app
./alive restart [service]one service, or all

Switching creators: ./alive down, then ./alive up <other>. One creator runs at a time.
