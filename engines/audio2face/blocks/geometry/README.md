## Representation is per-role, and the two compose

This is not MetaHuman versus FLAME. On monocular they compose: mono blocks the MetaHuman
Identity solve (`ECaptureDataInitializedCheck::Full`), so identity comes from a VHAP/FLAME
extreme-pose mesh wrapped and conformed, while animation still comes from the MetaHuman
Performance solve, which mono does not block.

Two kinds of flexibility, both needed:
- **swap** two entries in one role against the same contract
- **compose** one entry per role, mixed freely. The monocular path is a composition.
