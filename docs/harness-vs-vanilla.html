01

I did not add a loop to the workflow

I replaced the prompt, the way passages are delivered, the call structure, and the stopping rule — all at once. Five substantive changes, described as one.

That is the honest starting point, and it is why "the loop made it worse" was never a safe conclusion. When five things change together and the result drops, none of them is implicated.

05

What the chain of thought showed

Ten questions where the harness lost and the original did not. Captured the model's own narration at every turn.

Q: "I've been running every morning for about eight months..."
  turn 3   wrote the complete answer as prose      called no tool
  turn 4   "I'll verify the remaining passages"         called read_all
  turn 5   wrote the answer AGAIN, slightly shorter  called no tool
captured via harness/run.py:107 (thinking) and :122 · ten runs in /tmp/cot.json

the harness was rejecting finished answers

My loop saw no tool call, replied "Call a tool", and the model wrote the answer again. Measured across the ten: 16 answers written as prose and thrown away — 1.6 wasted drafts per question, and every single question did it.

Each redraft is shorter and sheds specifics. That is where the omissions came from. It was not under-retrieving — on those same ten it had read 54 passages.

the original loop: harness/run.py:124-127 before the fix · the fix: :131

No metric would have found this. The scores said the loop was structurally worse at not omitting things. The narration said the model answered correctly on the first try and was told to do it again. Reading what the model said, rather than what it scored, is what separated those.

07

Two things still not equal

1. it is not a superset

A fair test would have the harness start by doing exactly what the original does — four searches, all 43 passages in full — and only then optionally continue. Then it could only match or beat it.

As built it never presents passages the way the original does, so it is a different pipeline that happens to loop, not the original plus a loop.

2. every harness number so far was scored on the wrong judge

All the arms were measured by comparing the answer to the single passage the question was generated from. That judge was established as broken: across 600 answers it never once returned a match.

The replacement asks does it answer the question and is it grounded in what was retrieved, and every arm is being rescored on it.
